プライバシーポリシー

対象：アプリ「生活」（開発者本人1人だけが使う個人用アプリ）

使う情報

Google アカウントへのアクセスで、次の2つだけを使います。

  • Google カレンダーの予定（https://www.googleapis.com/auth/calendar.events）
  • Google Tasks のタスク（https://www.googleapis.com/auth/tasks）

使いみち

本人の予定とタスクを、本人の自宅のコンピューター上で動くアプリと両方向に同期し、本人に表示するためだけに使います。

保存する場所

同期した予定とタスク、および Google との接続に使う情報は、本人の自宅のコンピューターの中にだけ保存します。接続に使う情報は暗号化して保存します。

第三者への提供

Google から受け取った情報を、第三者に販売・提供・共有しません。広告にも使いません。外部のAIサービスにも渡しません。

Google API サービスのユーザーデータに関するポリシー

Google API から受け取った情報の利用と他アプリへの移転は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

削除

本人はいつでも Google アカウントの「サードパーティ製のアプリとサービス」から接続を取り消せます。取り消すと、アプリは Google の情報を読み書きできなくなります。

Privacy Policy (English summary)

This app is used only by its developer. It uses only the Google Calendar events scope and the Google Tasks scope, solely to sync the developer's own events and tasks with an app on the developer's home computer. Data is stored only on that computer; connection credentials are stored encrypted. Google user data is never sold, shared with third parties, used for advertising, or sent to external AI services. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time from the Google Account "Third-party apps & services" page.
